White Wine Quality Prediction – Machine Learning

Project Overview

This project focuses on predicting white wine quality using machine learning techniques in Python. It uses chemical properties of wine to predict quality scores and classify wine into quality categories.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Project Workflow

1. Data loading and exploration
2. Data cleaning and duplicate removal
3. Feature selection
4. Train-test splitting
5. Feature scaling using StandardScaler
6. Linear Regression model
7. Logistic Regression model
8. Model evaluation

Models Used

- Linear Regression
- Logistic Regression

Evaluation Metrics

- MAE
- RMSE
- R² Score
- Confusion Matrix
- Precision
- Recall
- F1 Score
- ROC-AUC

Objective

To analyze white wine characteristics and use machine learning models to predict wine quality.
